# Custom WordPress Training Portal & API Integration

## About the Project

I wanted to try building something a little more interactive with WordPress, so I came up with the idea of an aviation training portal where users can browse courses and find information about different training programs.

I also wanted to get more hands-on experience with PHP, React, and APIs and see how they could work together in a WordPress website.

## Project Features

- WordPress website customized with PHP, HTML, CSS, and JavaScript
- Course listings with descriptions and training information
- Search and filters to help users find courses
- React components for displaying course information
- WordPress REST API integration for retrieving course data
- Responsive layouts for desktop and mobile devices

## Tools Used

- WordPress
- PHP
- HTML5
- CSS3
- JavaScript
- React
- WordPress REST API

## My Approach

One of the main things I wanted to figure out was how to get course information from WordPress and display it through React instead of having everything hardcoded into the website.

I also wanted the portal to be easy to use, especially when searching for courses or looking through different training options. My focus was on keeping the design simple while getting the different parts of the website to work together.
